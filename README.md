# Swarm Robotics Project (MegaSwarm Extension)

## Overview
This project is part of my MSc Artificial Intelligence dissertation at Ulster University. It focuses on analysing autonomic swarm behaviour using a simulation-based approach.

The work contributes to a research study on swarm recruitment strategies and their impact on system-level performance.



## My Contribution
This project is based on an existing swarm simulation framework. My role focused on modifying and extending the system to support analysis and evaluation.

- Modified existing C# swarm simulation (MegaSwarm framework)
- Worked on agent behaviour adjustments within the simulation
- Implemented data tracking and monitoring for performance evaluation
- Supported analysis of swarm recruitment strategies
- Contributed to understanding emergent swarm behaviour



## Research Output
This work contributed to a research paper:

**"A Reproducible Framework for Evaluating Autonomic Swarm Recruitment"**  
Accepted at ICAS 2026



## Technologies Used
- C#
- Swarm Robotics Simulation
- Multi-Agent Systems
- Autonomic Computing Concepts



## About the Project
The simulation explores how autonomous agents coordinate in a decentralized environment using recruitment strategies and communication mechanisms.

The goal is to evaluate how different behaviours affect:
- Task allocation
- Resource utilization
- Overall swarm efficiency



## Note
This repository represents my contribution to a larger research project and focuses on modifications, analysis, and evaluation rather than building the system from scratch.
